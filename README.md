# Join Serge's World

**Free Minecraft Java survival with TaCZ guns, player trading, auctions, parties, and wilderness raiding.**

**Server address:** `pgsql-singles.tun.ply.gg:42022`

**Minecraft:** Java 1.20.1 · **Loader:** Forge 47.4.10 · **Pack:** 1.0.0

## Download and play

1. [Download the Serge's World client pack](https://raw.githubusercontent.com/cryptocurrencypi/serges-world/main/downloads/serges-world-1.0.0.mrpack).
2. Install the free [Modrinth App](https://modrinth.com/app) or [Prism Launcher](https://prismlauncher.org/download/).
3. Import the downloaded `.mrpack` file. In Prism, choose **Add Instance → Import** and select the file. In Modrinth, choose **Create instance → Import from file** and select the file. The launcher downloads the matching Minecraft, Forge, and mods.
4. Sign in with your Minecraft Java account and launch **Serge's World**. Allocate around 4 GB of memory if your computer has enough RAM.
5. Open **Multiplayer**, select **Serge's World**, and click **Join Server**. If it isn't listed, choose **Add Server** and paste `pgsql-singles.tun.ply.gg:42022`.

The game and a legitimate Minecraft Java account are required. Joining this server and downloading this pack are free. Bedrock, vanilla Minecraft, NeoForge, and Minecraft 26.2 are not compatible with this pack.

## How the world works

- Survival and PvP, with guns from TaCZ.
- Raiding and looting are allowed outside spawn. Protect your own base through building and strategy; player land protection is disabled.
- The server-owned spawn/shop area covers **X 272–351, Z −48–31**, around spawn **X 310, Z −3**. Block, PvP, and explosion protection are configured there. TaCZ interactions still need a live gameplay protection test.
- Lightman's Currency provides coins, banks, player traders, and auctions. The economy framework is installed; a staffed or stocked spawn shop is not yet built.
- Parties are available through `/oparties`; use `/oparties` in game to see available commands.
- Initial capacity is **8 simultaneous players**. The world is in an early public test phase.

## Rules

1. No cheating, exploit abuse, duplication exploits, or attempts to bypass spawn protection.
2. No harassment, threats, hate speech, or sharing other players' private information.
3. Wilderness raiding is allowed; griefing or attacking the protected spawn/shop area is not.
4. Only administrators install server mods or change server rules. Joining never grants administrator access.

Fiw AntiCheat checks client mod information for configured cheat signatures. AntiXray runs on the server. These measures do not guarantee that every cheat is detected. Ordinary operational logs are retained on the server.

## Connection help

- **Mismatched mod channel list:** import this pack into a fresh instance, or check the versions above. Fiw must be the **Forge** file, not NeoForge.
- **Missing Lightman's Currency:** install version **2.3.0.6 for 1.20.1** and restart the game.
- **Cannot connect:** include the port `:42022`, check that the server isn't full, and retry after any brief maintenance window.
- **Wrong game version:** use the pack's Forge 1.20.1 instance.
- Report technical problems through [GitHub Issues](https://github.com/cryptocurrencypi/serges-world/issues). Never post passwords, account details, home addresses, or private logs.
